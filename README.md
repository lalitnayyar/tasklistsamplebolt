# Todo App

A simple and elegant Todo application built with React and Tailwind CSS. Manage your tasks efficiently with a clean and responsive user interface.

## Features

- **Add Todos**: Easily add new tasks to your todo list.
- **Mark as Complete**: Toggle tasks between completed and incomplete states.
- **Responsive Design**: Works seamlessly on both desktop and mobile devices.
- **Clean UI**: Built with Tailwind CSS for a modern and minimalistic look.

## Functionality

- **Add a Todo**:
  - Type your task in the input field and click the "Add" button.
- **Complete/Undo a Todo**:
  - Click the "Complete" button to mark a task as done.
  - Click the "Undo" button to revert a completed task back to incomplete.
- **View Todos**:
  - All tasks are displayed in a list, with completed tasks shown with a line-through and grayed out.

## User Guide

1. **Adding a Todo**:
   - Enter your task in the input field at the top of the app.
   - Press the "Add" button or hit Enter to add the task to your list.

2. **Completing a Todo**:
   - For each task, click the "Complete" button to mark it as done.
   - The task will be visually indicated as completed.

3. **Undoing a Completed Todo**:
   - If you want to revert a completed task, click the "Undo" button.
   - The task will return to its incomplete state.

4. **Responsive Design**:
   - The app is fully responsive and works on all screen sizes. Resize your browser or open it on a mobile device to see the responsive layout in action.

## Technologies Used

- **React**: A JavaScript library for building user interfaces.
- **Tailwind CSS**: A utility-first CSS framework for rapid UI development.
- **Vite**: A fast build tool for modern web development.

## How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/todo-app.git
   ```
2. Navigate to the project directory:
   ```bash
   cd todo-app
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Open your browser and navigate to `http://localhost:5173` to view the app.
